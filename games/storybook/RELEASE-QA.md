# 四款單機遊戲上線檢查

日期：2026-09-13。範圍：心光合成屋、星願飛行郵差、森林急件快遞、四葉草探險地圖及大廳四個入口。既有遊戲未更動。

## 已完成

- 生成場景、角色元素收藏球、載具、角色動作、棋盤圖集與四張封面；以 WebP 提供，保留原有透明通道。介面排版與狀態由 CSS 控制，美術以圖像呈現。
- 四款遊戲皆有角色選擇；跑酷提供三位具有不同實際能力的角色，其餘三款提供十位陪伴角色。飛行各角色採相同碰撞範圍。
- 四首 CC0 背景音樂、互動音效、音量控制與靜音；來源、作者及隨包授權保存在 CREDITS.html 與 audio/。
- 本機保存音量、角色、操作設定、收藏、解鎖與分模式紀錄。練習不列入正式成績。
- 合成與飛行在手機採直向；跑酷採橫向；踩地雷小圖不限，大圖提醒橫向。方向不合會暫停並顯示提醒。

## 驗證結果

- 所有新增 JavaScript 語法檢查通過；84 個靜態資源引用確認存在；音訊 MP3 解碼通過。
- Chromium 實際頁面：四款載入、開始、暫停、返回、結算、角色選擇均可操作，測試過程未出現未處理頁面錯誤。
- 合成：真正的 Matter.js 碰撞只合成一次、投球冷卻、練習撤回、暫停、任務過關、持續超線結束。
- 飛行：上升與重力、通道安全區、柱體碰撞、信件收集、邊界失敗、進度解鎖、練習隔離；自動操作通過六段關卡，使用正常物理及障礙產生流程。
- 跑酷：短跳／長跳高度、下滑通過枝葉、站立碰撞、毛毯一次保護、月光減速與冷卻暫停、幸運吸信；三位角色各通過三條配送路線，共九組通關。
- 踩地雷：60 張隨機推理解謎棋盤逐張檢查陷阱數、首點鄰域、相鄰數字及求解器可解性；不需全部插旗也能勝利；長按與原生右鍵事件不重複切換；捲動不誤翻格；同圖練習保留棋盤與安全開局。
- 瀏覽器實際音樂播放、音量與角色重載保存、聲音設定暫停遊戲通過。
- 桌面及 390 × 844、844 × 390、320 × 740 視窗檢查；手機直橫提醒、大棋盤局部捲動、跳躍鍵與聲音按鈕不互相遮擋。

## 驗證範圍

手機以 Chromium 視窗與觸控條件模擬檢查，尚非每款 iOS／Android 實機測試。遊戲為純前端，收藏只保存在目前瀏覽器，清除網站資料會重設紀錄。推理解謎限定 9 × 9，產生器未找到合適棋盤時會要求重試，不會提供未通過求解驗證的棋盤。
