# CxQ 心光對決

十位 CxQ 原創角色的單機 1 對 1 格鬥遊戲。故事五場與十個專屬結局、自由對戰、訓練、生存、本機雙人均可從首頁進入。所有角色開放；收藏不增加戰鬥能力。

正式版本 20261008-complete1，入口 arcade/index.html，舊入口自動轉至街機版。固定 1280×720 橫式舞台，直式顯示旋轉提示，首頁模式鍵加大，遊戲內阻止雙擊與手勢縮放。戰鬥模擬固定 60 Hz，畫面隨 requestAnimationFrame 繪製；自動畫質連續三次低於 45 FPS 時降低解析度與特效，判定不變。40 FPS 是驗收目標，本機瀏覽器觀察約 75 FPS，不能當作手機實機保證。

十位角色各新增上挑、低掃、空中攻擊與終結技，每招三張獨立生成的透明動作圖，共 120 張。每張保留獨立來源與提示詞，沒有從大圖切割或用舊姿勢變形代替；既有待機、走路、基礎攻擊、防禦及受擊素材繼續使用。各圖依透明邊界與腳底定位，碰撞判定與畫面定位分開計算。素材及提示詞见 ../refresh-20261008/manifest.json、asset-jobs.json。

下＋技能為上挑，下＋重攻為低掃，空中攻擊使用新動作，連段兩次命中後重攻可接終結技。十位角色依速度、武器、技能與攻擊段位安排不同路線，訓練可逐招及整段示範。輸入緩衝 0.32 秒，命中取消及上挑跳躍取消改善銜接，保留五段脫離保護。

audio-v2 包含五首本次創作的多樂器循環配樂及 27 個獨立音效／角色音色。音樂、音效音量分別設定，解碼緩存、最多 12 個同時音效、動態壓縮與聲道定位，頁面隱藏／離開時暫停。音訊由第一次玩家操作解鎖。

首頁、選角、共用戰鬥、角色與舞台分包下載，首頁只需要 menu.bin；對戰只載入兩位選定角色與當前舞台。每張圖仍獨立編碼，沒有大圖裁切。ES2022 入口合併為 app.bundle.mjs，錯誤下載可重試，已完成下載與解碼重用。

玩家一：A / D 移動、S 蹲下、Space 跳躍、J 輕擊、K 重擊、L 技能、I 按住格擋、U 必殺。玩家二：方向鍵、數字鍵盤 1 / 2 / 3 / 0 / 5。可重設兩組按鍵。輕重同按是近距離投技；方向雙點衝刺。手機使用固定方向盤和六鍵；方向盤雙點左右也可衝刺。標準手把：左搖桿／方向鍵、A 跳、X 輕、Y 重、B 技能、LB 格擋、RB 必殺、Start 暫停。

三戰兩勝、每回合 60 秒；同分重赛不增加勝場。必殺消耗 100 能量。防守分站立／低段，投技不可格擋。連段傷害遞減，五次命中強制擊倒並給起身保護。訓練提供站立、格擋、反擊、近遠距離重置及判定顯示。生存單回合，勝利保留生命並回復 20%。

localStorage 使用 cxq-heartlight-duel-arcade-v2，可下載／匯入具校驗碼的 JSON 備份；每次更新保留先前健康版本，損壞時先嘗試備份，兩者都損壞則保留原文供匯出。同格式舊紀錄補入音量預設，新招可保存與恢復。無登入、雲端同步或網路玩家對戰。

規則與存檔：node tools/test-heartlight-arcade.mjs；新招／取消／十角色連段：node tools/test-refresh-combat.mjs；291 張分包圖片、比例、透明度、緩存及重試：node tools/test-arcade-packs.mjs；音訊：node tools/validate-refresh-audio.mjs；全站新增美術完整性／獨立來源：node tools/validate-refresh-assets.mjs。瀏覽器驗收不代表 Android／iPhone／實體手把驗收。
