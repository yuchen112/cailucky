# CxQ 心光對決

十位 CxQ 原創角色的單機 1 對 1 格鬥遊戲。故事五場與十個專屬結局、自由對戰、訓練、生存、本機雙人均可從首頁進入。所有角色開放；收藏不增加戰鬥能力。

戰鬥模擬固定 60 Hz，畫面隨 requestAnimationFrame 渲染。實際 FPS 顯示在戰場；自動畫質連續三次低於 40 FPS 時降低解析度、網格與特效數量，判定不變。40 FPS 是效能目標，並非每個動作需要 40 張素材。

角色沿用十位夥伴獨立製作的 ready、cast、victory 透明素材，以動作時間、網格變形、跳躍、倒地與姿態轉換驅動。不是逐動作手繪影格素材包。封面和四個場景各自獨立生成，見 art/manifest.json、art/prompts.json。音樂沿用 ../shared/audio/heavenly.mp3 與 sherwood.mp3，授權來源見 ../shared/audio/CREDITS.md；命中音效由 Web Audio 產生。

玩家一：A / D 移動、S 蹲下、Space 跳躍、J 輕擊、K 重擊、L 技能、I 按住格擋、U 必殺。玩家二：方向鍵、數字鍵盤 1 / 2 / 3 / 0 / 5。可重設兩組按鍵。輕重同按是近距離投技；方向雙點衝刺。手機使用固定方向盤和六鍵；方向盤雙點左右也可衝刺。標準手把：左搖桿／方向鍵、A 跳、X 輕、Y 重、B 技能、LB 格擋、RB 必殺、Start 暫停。

三戰兩勝、每回合 60 秒；同分重赛不增加勝場。必殺消耗 100 能量。防守分站立／低段，投技不可格擋。連段傷害遞減，五次命中強制擊倒並給起身保護。訓練提供站立、格擋、反擊、近遠距離重置及判定顯示。生存單回合，勝利保留生命並回復 20%。

localStorage 使用 cxq-heartlight-duel-v1，可下載／匯入具校驗碼的 JSON 備份；每次更新保留先前健康版本，損壞時先嘗試備份，兩者都損壞則保留原文供匯出。無登入、雲端同步或網路玩家對戰。

規則、十角色行為、AI 邊界、五段保護、存檔及素材測試：node tools/test-heartlight-duel.mjs。瀏覽器響應式驗收不代表 Android / iPhone / 實體手把驗收。
