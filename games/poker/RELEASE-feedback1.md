# 選牌操作回饋（2026-09-29）

- 大老二、排七、撿紅點選牌時，使用引擎副本驗證合法性，不寫入存檔，
  不显示預測輸贏或隱藏牌。無有效選牌時停用出牌鍵。
- 顯示已選張數、牌型或不能出牌的原因，新增清除選牌。
- 撿紅點選擇目標後保留「已選」美術標籤；唯一可配對目標自動標示，
  多個目標需自行選擇。桌牌不向上抬，避免壓到提示。
- 操作失敗保留內部選牌狀態，不再與畫面標示不同步。
- 保留上一版未完成牌局切換與存檔行為。

驗證：56 項撲克測試通過。640×320 瀏覽器實際檢查選牌、非法組合停用、
目標選擇、清除選牌；四顆操作按鈕均 44px 高且在畫面內。
沒有瀏覽器 JavaScript 錯誤。非實體 Android 測試。

此批是操作回饋修正，沿用現有逐張牌面與 UI 美術；未新增角色動作圖，
不代表所有角色動畫與其他遊戲的待辦已完成。
