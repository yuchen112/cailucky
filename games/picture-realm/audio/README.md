# 幻裝圖境：夢幻拼圖畫室聲音設計

此套配樂、旋律、合成音色與擬音專為本遊戲製作，沒有引用其他 CxQ 遊戲錄音、第三方音樂或樣本。創作方式為原創程式編曲與聲音合成，不宣稱為 AI 音樂生成或真人錄音。

## 四首循環配樂

- 星光畫室（首頁）：80 BPM，暖鋼琴、音樂盒、柔和和聲。
- 方塊漫步（華容道）：88 BPM，較清楚的撥奏節奏與輕快鋼琴。
- 拼片午後（凹凸拼圖）：76 BPM，低音區柔鋼琴與舒緩和聲。
- 珍藏相簿（圖鑑、大圖、完成畫面）：72 BPM，稀疏音樂盒與星光旋律。

各曲使用完整 16 小節結構，音尾與空間殘響循環回捲，場景切換時淡入淡出；暫停與確認對話框時降低音樂音量。播放檔為 MP3，WAV 保留為無損製作母帶。

## 十六種音效

tap、slide、pickup、place、snap、rotate、hint、undo、start、pause、resume、page、download、error、win、unlock。

核心辨識為「瓷片與絨布畫板」：滑動含短摩擦與歸位輕扣；拼片接合含瓷質扣合與玻璃星砂；圖鑑含紙頁聲。通關與首次圖鑑解鎖分別使用暖和弦與高音星光樂句。

## 執行與設定

首次指標或鍵盤操作後才建立音訊環境，音檔按需載入並快取。音樂與音效可獨立開關及調整音量，保存在既有存檔；舊存檔自動補齊新設定。切至背景時停止聲音並暫停音訊環境，返回後依原設定恢復。最多十個音效同時發聲，快速操作有節流。

## 再製作

需要 Python、NumPy 與 FFmpeg：

```text
python tools/render-audio.py
python tools/encode-music.py <ffmpeg-path>
node --test tools/test-audio.mjs
```

音檔清單、時長、峰值與 SHA-256 見 manifest.json。瀏覽器已驗證 20/20 音檔解碼、四場景切換、背景停止，以及實際移動／拿取／放置／通關／解鎖流程。尚未在實體 iPhone 或 Android 驗證喇叭輸出。
