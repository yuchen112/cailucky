# 經典遊戲館：手機遊戲內頁重製

本次修改範圍為遊戲館內 12 款遊戲。大廳、機台排序、入口與正式 main 分支不在修改範圍內。

## 畫面與美術

- 新整備介面保留原始控制節點、事件與選項，改為圖像化選擇卡及角色選擇區；整備內容可捲動，開始操作保持可觸及。
- 共用 AI 素材涵蓋介面材質、十位角色的跑步／跳躍／滑行／站立／勝利姿態、四種載具組合、棋子、障礙、道具、地鼠洞與特效。
- 遊玩 HUD、操作區、暫停、教學、確認及結算介面使用同套素材。既有重繪素材仍由 `mobile-art`、`mobile-brand`、`atelier` 提供。
- CSS 處理排版、互動狀態及功能性標記；角色、場景、面板和圖示使用點陣美術。
- `manifest.json` 列出本目錄的 WebP 檔案、大小與 SHA-256。

## 驗證

`qa-report.json` 記錄 204 組模式／內容的進入、輸入與暫停檢查、12 款方向檢查，以及觸控、結算與紀錄檢查。部分結算測試以隔離 fixture 觸發原引擎的結算處理；204 組檢查不代表 204 次自然通關。

瀏覽器測試涵蓋一般與小尺寸手機視窗、素材與程式載入。Chrome 觸控模擬不等於實體手機手感驗證。
