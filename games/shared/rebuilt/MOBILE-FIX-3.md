# 2026-11-09 特殊方塊、出洞與暫停修正

## 三消

更換不存在的舊特殊素材，特殊標記固定於實際格子中心並與寶石一起交換、下落；直向箭頭旋轉90度。修正彩虹主動交換後多清除底色的錯誤。角落小寶石標示連鎖觸發彩虹時使用的底色，玩法說明補上方向、無效交換、連動及底色規則。

14項規則與實際引擎 fixture 檢查記錄於 specials-fix.json，包含真實交換生成位置與重力下落、無效交換退回、兩種直線範圍與雙彩虹。fixture 不代表自然遊玩通關。

## 森林敲敲樂

新地面背景與後洞口／前洞緣，角色下身由洞緣遮擋。出洞進度取自遊戲時間，同時控制位移與裁切；180ms出洞後才進入原有命中窗口，命中260ms縮回、逾時180ms退回。暫停時動作同步停止，不使用牆鐘動畫。7項命中與遮擋檢查記錄於 whack-hit-window.json。

## 暫停

十二款使用固定於視窗的覆蓋暫停介面，面板以內容高度置中。補上2048、翻牌、泡泡龍、三消的獨立暫停入口，連連看暫停遮罩改成原生dialog並沿用原引擎的paused狀態。重玩與離開需確認，取消保留暫停。翻牌不再沿用整備表單高度，方塊與打磚塊繼續時先關閉面板再倒數。輸入、計時與現有動畫暫停；觀察器只處理對話框結構與狀態，避免掃描每幀分數／角色更新。

Chrome與Windows WebKit、390x844／844x390及320x568／667x375視窗：十二款各連續3次暫停／繼續，核對計時、輸入解鎖、面板不裁切或捲動、文件不增高、離開確認取消。另檢查四款自訂暫停返回首頁後可重新進入。瀏覽器模擬不等於iPhone實機驗收。
