# CxQ 童話塔防 — 重製工作區

狀態：夢境守護重製試玩版。正式入口連至 army.html；以下早期核心構想保留作設計沿革，現行交付範圍以 RELEASE-evolution1.md 為準。

## 核心體驗

直式手機單手操作，以原創 CxQ 角色守護森林。參考 Summoner's Greed 的固定部署與自動戰鬥概念，不複製其人物、畫面或素材。九個部署台，十位原有角色全部可選，同角色不可重複；部署、升級、撤回，搭配單體、範圍、減速與支援。闖關與無盡共用可測試的規則核心。

角色名稱以網站既有資料為準：幸運、夢想、成長、快樂、夜晚陪伴、悲傷、信任、回憶、療癒、希望。

## 畫面與對位契約

- 戰場座標 390 × 585，完整戰場只用同一比例縮放，角色、路線、地台不能各自縮放位移。
- 背景與道路是各自獨立生成的完整素材，道路不是拼切圖集。道路圖產出後必須人工校正路徑，不假定生成結果精確服從座標。
- 所有角色以腳底錨點部署，投射物在攻擊動作的釋放時刻出現，碰撞時才扣血。
- UI 使用各自生成的完整底板／按鍵；動態文字以可讀 DOM 字體疊加，CSS 只負責排版、互動、素材播放，不畫插圖。
- 世界鏡頭不隨手機工具列跳動。橫式暫停並顯示旋轉提示；背景頁、說明、設定一律暫停。
- 非同步載圖完成以前不可開戰。輸入不能穿透選單。開戰、結算不得重複觸發。

## 素材與動畫驗收

每個素材單獨生成一張，單一動作姿勢單獨生成一張；禁止從大型拼貼或 sprite sheet 裁切。WebP 只做整張等比例縮小，不裁圖。

必需素材：戰場地景、道路、地台、守護目標、首頁、標題、按鍵、設定底板、角色卡底板、血量槽、選取標記、貨幣、旋轉提示、勝敗插畫。

十位角色各需：待機、蓄力、釋放、恢復、受擊／互動、勝利。敵人至少四類：步行左右交替、受擊、退場；頭目另有進場與技能。效果各自成圖：投射物、命中、範圍、減速、護盾、治癒、升級。獨立圖片序列與時間軸共同驗收，不能只用同一圖上下晃動代替動作。

未齊全的素材不得以 CSS 圖示冒充完成品。開發預览僅用於規則與對位檢查。

## 發佈門檻

1. 所有角色身份／名稱與網站一致，完整動畫素材清單經人工目視確認。
2. 手機 360×640、390×700、412×915 及短高度畫面：可讀、可點、無頁面位移、無模糊補邊。
3. 主頁→部署→戰鬥→升級／撤回→勝敗→再玩／退出→存檔／匯出匯入完整流程。
4. 減速／範圍／護甲／多枚同時命中／漏怪／最後敵人／暫停／重開／舊存檔與損壞存檔測試。
5. 實測首屏素材大小與載入；瀏覽器模擬不宣稱等於 Android 實機驗收。
6. 測試通過且素材齊全才替換正式入口、部署與比對线上版本。

目前不移除舊美術，以免刪到其他遊戲共用素材；待新版本完成後依引用清單清理。
