# 整合版製作契約

本轮目標：封面與營地、英雄視覺與判定一致、獨立動作圖、區域路線、升級用途、養成及可驗證抽取交易、授權音樂、手機整體驗證，完成整合再交付。

- 保留原十位 IP 英雄姓名與身分，全開；熟練度提供選擇。
- 圖片逐張製作，不用圖集切片。UI CSS 只負責排版、可讀文字、互動；新裝飾必須使用素材。
- 英雄三處獨立指揮點，位置、攻擊起點及範圍一致，不壓住一般部署點。
- 素材先定尺寸、腳底、角度和用途；舊圖保持可回復，不刪除未確認無引用素材。
- 首頁先可用，素材具進度及重試；存檔交易先完成驗證再原子儲存。
- 三區不同道路及對應碰撞路線，敵人顯示與判定使用同一座標。
- 抽獎以永久圖鑑／部隊訓練收藏為主，不锁基础通關。一次首次通關獎勵、清楚機率、保底、重複交換與持久化紀錄。
- 測試區分核心單元、模擬關卡、瀏覽器實際操作、正式站、Android 真機。未做真機不冒稱完成。
