# CxQ 幸運小鎮 · 收藏與小屋擴充版

固定橫式、純金幣的角色生活遊戲。首頁與遊戲大廳維持「製作中｜可遊玩」，遊戲不設返回網站按鈕。

## 本版內容

- 88 件家具：保留原有 24 件，新增暖木居家、花園午茶、星月臥室、糖果甜屋、魔法書房、森林小屋、皇家客廳、海邊度假八個系列，每個系列八件。每件有占地、用途與互動；桌櫃可放花瓶，沙發及床可放抱枕。
- 90 種造型：十個角色各有原裝及八套專屬服裝。新增每人睡衣、旅行、職業、冬日與節慶五套，共 50 套；每套有獨立站姿、四張走路素材及坐姿。保持角色身份、物種與個性，不共用服裝或配件。
- 12 種室內背景：保留三個舊背景，新增八系列房間及晨光玻璃屋。背景不畫固定家具，換背景保留原有布置與人物比例。
- 六種可購窗景：花園、森林、小鎮、海岸、星空、雪日；可免費切回原有窗景。窗景在相容的窗戶開口中獨立繪製，有輕微景物位移，減少動態時停止。
- 家具、服裝調漲約 2.5 倍；舊房間背景同樣調漲，新收藏分級定價。已購收藏完全保留，不補收差額。背景及窗景購買一次，十位角色共用收藏、各自保存選擇。
- 商店有家具、專屬套裝、房間背景與窗景四類，提供系列／角色、用途、已收藏／未擁有／買得起篩選。每頁六件，衣櫃每頁四種造型，維持橫式主要操作不捲動。
- 房間背景與窗景以目前角色及自己的家具預覽。系列家具可整套預覽、一次購買尚未擁有的項目；不重複買已收藏的家具，也不改動目前布置。
- 四隻金幣領養寵物保留跟隨、走路、睡覺、摸摸與慶祝，不增加每日餵養負擔。人物有避障走動、坐下漸變、家具互動及拍照。

## 遊戲收益

六台保留中央連線、甜點連鎖、鎖星重轉、花園累積、選軸保留、相簿累積六種玩法。下注倍率為 1／5／10／25／50，獎金同比例放大，倍率不改變機率；累積進度各倍率獨立保存。

新結果依各台玩法安排，顯示的圖案、連線、星星與累積獎必須和實際結算一致。已有待結算旋轉或刮卡保留其原始結果，不因更新重抽。

| 玩法 | 有獎方向 | 回饋方式 |
| --- | --- | --- |
| 四葉幸運 | 約 72% | 兩同常見，三同較少見，三幸運草約 0.5% |
| 甜點連連 | 約 70% | 更常出現三連，連鎖依實際補落圖案結算 |
| 星月收藏 | 約 95% | 星星小獎頻繁，重轉後按最終星數給獎，滿星大獎約 0.4% |
| 花園成長 | 約 72% | 每片葉子都有金幣，18 葉開花獎保留 |
| 玩具百變 | 初轉約 72% | 可收獎或免費保留一軸重轉；重轉取代目前結果 |
| 回憶相館 | 約 72% | 相機小獎與三同獎，累積一頁另給獎金 |
| 九款刮卡 | 約 80% | 約 50% 結果真正賺錢，回本、小賺比大獎常見 |

機率為大量模擬的近似值，不保證個別遊玩結果。有獎、回本、淨賺及大獎分開統計；花園與相簿模擬包含連續累積進度。純娛樂金幣整體長期收益偏正向，沒有現金兌換。模擬報告位於 `preview/lucky-town/v4/economy.json`，每玩法 100,000 筆，總共 1,500,000 筆。

小獎縮短跳數與入帳演出，5 倍起為較大的慶祝，20 倍起為大獎演出；可使用快速模式、略過或減少動態。慶祝素材載入等待有上限，避免因網路延遲卡住結算。

## 刮刮樂與操作

三圖相同、幸運號碼、小屋驚喜各有 20／100／500 金幣的獨立票框及版面，分別有 6／10／15 區。最高獎為面額的 10／10／20 倍；高面額有較大的版面與加碼配置。

整張票共用覆膜及 pointer capture，手指不必抬起即可跨區刮；快速滑動補齊路徑，有刮屑與声音。刮痕與既定獎金一起保存，重整接續，收獎一次。舊版九格刮卡也可接續完成。

直式顯示轉向提示，全螢幕在支援的瀏覽器嘗試鎖定橫向。雙擊、雙指縮放、舞台拖動與同位置快速連點有防護；商品及確認視窗也防重複扣款。對話框及布置庫存保留獨立捲動。

初始 1,000 金幣；低於 100 時完成三次小互動及二十秒準備，補到 300，共用三分鐘冷卻。沒有新增排行榜、限時搶購或必做每日任務。

## 存檔與相容

儲存鍵仍是 `cxq-lucky-town-v1`，封裝版本仍為 1，內容升級為 `dataRevision: 3`。localStorage 與 IndexedDB 另外保存受保護的新版副本（collection-v3／current-v3），舊版分頁即使寫入更高修訂號也不能取代新版收藏；保留五份有效備份與受損原始資料。升級前的完整原始封裝加入備份，不重置金幣、家具、小屋、角色套裝、寵物與待結算遊戲。

新增窗景收藏及每位角色的小屋窗景。背景、窗景、家具、穿搭及進度一起匯出、匯入；本機保存不等同雲端，清除瀏覽器資料後需使用事先下載的 JSON 備份。

扣款與結果先保存再演出，Web Locks 序列化跨分頁操作。過時分頁先取得新紀錄並要求重試，小屋編輯检查房間是否被其他分頁修改。

## 美術與驗證

美術使用內建 imagegen 工具，按獨立素材產生，不使用圖集裁切。新增素材及來源 PNG 保存在 `games/lucky-town/art/`；正式使用 `.webp`。完整提示詞、參考圖與來源路徑保存在 `art/generation-v4-prompts.json`，編碼由 `tools/prepare-lucky-town-v4-art.py` 重現，PNG 原稿不取代正式 WebP。

新增 379 張素材：64 家具、50 套裝站姿、200 走路、50 坐姿、9 背景、6 窗景。整體 manifest 共 712 張圖。透明邊緣及動作對照板由 `tools/check-lucky-town-v4-art.py` 檢查，對照板在 `preview/lucky-town/v4/`。

執行 `node tools/test-lucky-town-v4.mjs` 驗證收益、圖案結算、收藏與舊存檔升級。`node tools/check-lucky-town-full.cjs` 驗證橫式尺寸、連續刮卡、連點防護、十二種背景、購買、九十種造型、機台、音效、存檔與網站入口；使用獨立瀏覽器存檔，不改動玩家紀錄。設置 `LUCKY_TOWN_URL` 與 `CAILUCKY_URL` 可測公開站。

音樂與音效沿用已收錄的十七個音訊檔，授權與出處見 `audio/` 內的紀錄。

測試主機的 Edge HTTP/2 連線曾造成部分圖片請求持續等待；HTTP/1.1 可正常載入。同一套瀏覽器流程可設置 LUCKY_TOWN_HTTP1=1 重現此連線設定，不修改遊戲規則或素材。實際 Android／iOS 裝置尚未驗證。
