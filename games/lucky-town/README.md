# CxQ 幸運小鎮 · 第二版

網站遊戲大廳入口標示「製作中｜可遊玩」。純金幣：拉霸及刮刮樂扣金幣、結算加金幣，家具、套裝、寵物與擴建直接用金幣購買。

## 內容

- 10 個原有角色自由入場，各自保存小屋、穿搭、預設、寵物選擇與拍照紀念；共用金幣和收藏。
- 6 種機台：中央連線、消除連鎖、鎖星免費重轉、花園累積、選軸保留重轉、相片累積。
- 每台保存 1／5／10／25／50 倍下注；扣款和獎金同比例增加，機率不變。花園與相簿進度依下注倍數分開保存。
- 24 件家具、30 件角色專屬付費套裝（每人原裝＋居家／日常／盛裝三套）、3 種房間主題。配件商店移除，舊配件按原價一次退款。
- 三種刮刮樂：三圖相同、幸運號碼、小屋拼圖，售價 20／100／500 金幣。手指或滑鼠擦除覆膜，刮痕與既定結果保存，完整揭曉後一次收獎。
- 四種金幣領養寵物，可命名、為角色選擇陪伴者；跟隨、走路、休息及點擊回應。無餵養扣款。
- 40 種角色造型各有站姿、坐姿與兩張獨立步行素材；小屋自動走動、避開家具、點擊走路、坐下與家具互動。照片保留當時人物和寵物位置。
- 逐軸滾動、停軸音效、消除落下、鎖星重轉、進度完成演出、獎金跳數、金幣飛入錢包；可略過演出、快速旋轉或減少動態。
- 格子布置、拖曳／點選／方向鍵移動、旋轉、收回、撤銷重做、桌面與座位擺飾、房間擴建。
- 初始 1,000 金幣；低於 100 時完成三次小互動及 20 秒準備，補到 300；共用 3 分鐘補助冷卻。

## 存檔

`cxq-lucky-town-v1` 使用封裝與 checksum，在 localStorage 和 IndexedDB 各保存一份，保留最近 5 份有效紀錄。旋轉扣款與結果先保存再演出；重整接續結算。刮刮樂按張保存既定獎金、部分刮痕及收獎狀態。Web Locks 序列化跨分頁提交；過時分頁載入最新紀錄後要求重試。小屋編輯檢查角色與房間是否遭另一分頁更新。

更新先保留原始舊版封裝，再轉換套裝、下注、寵物欄位並一次退款。匯入驗證 checksum、物品、角色套裝、家具數量與位置、下注與刮卡狀態，預覽後還原，先備份目前紀錄。全部副本受損時保留原始資料，阻止新遊戲覆蓋，接受有效備份恢復。

照片圖檔下載到裝置，相簿保存最近 20 次日期與名稱。清除網站資料可能清除兩份本機儲存，請定期下載 JSON 備份。無帳號或雲端同步。

## 美術與音樂

內建 imagegen 工具生成獨立封面、街區、舞台、機台館、刮卡桌、房間、UI、機台、符號、家具、套裝、角色步行與坐姿、寵物與姿勢。原有角色圖為身份參考；每件素材獨立生成。原始 PNG 保留本機 `art/`，部署 WebP 保留透明度。方向及參考記錄見 `art/generation-prompts.json` 和 `art/generation-v2-prompts.json`。

4 段背景音樂及 13 種下載音效：Kenney CC0 音效；Kevin MacLeod 的 Carefree、Daily Beetle、Pixelland、Wallpaper 為 CC BY 4.0，已註明作者、來源、授權與剪輯。來源見 `audio/sources.json` 及設定中的製作名單。音樂／音效獨立音量、首次操作解鎖、換場淡入淡出、隱藏分頁暫停。

## 驗證

在儲存庫根目錄執行：

```
node tools/test-lucky-town.mjs
node tools/test-lucky-town-v2.mjs
node tools/serve-lucky-town.cjs
node tools/check-lucky-town-v2.cjs
node tools/check-lucky-town-persistence-v2.cjs
node tools/check-lucky-town-recovery.cjs
node tools/check-lucky-town-house-backup.cjs
node tools/check-lucky-town-life-audio.cjs
node tools/check-lucky-town-assets.cjs
```

瀏覽器工具以 `LUCKY_TOWN_URL` 指定遊戲網址；入口工具使用 `CAILUCKY_URL` 指定網站根網址。`check-lucky-town-full.cjs` 依序執行完整瀏覽器檢查。涵蓋實際購買、退款、角色入場、全部造型載入、小屋、拍照下載、六機台轉軸、刮卡擦除與重整接續、音量控制、50 倍中斷結算、受損紀錄恢復、跨分頁及五種尺寸（320×568、390×600、390×844、412×915、1280×900）。報告保留本機 `preview/lucky-town/v2/`；手機尺寸模擬不等同 Android／iOS 實機驗證。
