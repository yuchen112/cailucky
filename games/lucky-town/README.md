# CxQ 幸運小鎮 · 橫式版

網站首頁及遊戲大廳標示「製作中｜可遊玩」。純金幣玩法：拉霸及刮刮樂扣金幣、結算加金幣，家具、套裝、寵物及擴建直接購買。

## 介面與內容

- 固定橫式操作，直式顯示轉向提示；全螢幕按鈕在支援的瀏覽器嘗試鎖定橫向。主要場景、操作及導航留在同一畫面，商店每頁六件商品，布置庫存及長對話有獨立捲動區。處理安全邊界及橫直切換。遊戲不設返回網站按鈕。
- 十個角色自由入場，各自保存小屋、套裝、穿搭預設、陪伴寵物及拍照紀念；金幣和收藏共用。選角有完整人物舞台、角色介紹與十人選擇列。
- 六種機台：中央連線、消除連鎖、鎖星免費重轉、花園累積、選軸保留重轉、相片累積。每台保存 1／5／10／25／50 倍下注；扣款與獎金同比例增加，機率不變。花園與相簿的倍率進度分開保存。
- 二十四件家具、三十件角色專屬付費套裝；每人原裝＋居家／日常／盛裝，共四十種造型。三種房間主題。配件商店已移除，舊配件按原價一次退款。
- 四種金幣領養寵物，可命名與選擇陪伴者；跟隨、走路、睡覺、摸摸回應與中獎慶祝。沒有每日餵養負擔。
- 四十種造型都有坐姿及四張獨立步行素材。人物會避開家具走動、轉向、與家具互動；站坐漸變，角色待機節奏不同，寵物有獨立反應圖。照片保留拍照時的姿勢與位置。
- 真正轉軸滾動、加速與停軸、消除落下、鎖星重轉及累積完成演出。中獎分級顯示金光、金幣雨、獎金跳數及錢包入帳；可略過、快速旋轉或減少動態。原始角色有獨立慶祝圖，其他套裝保留正在穿的服裝並播放動作。
- 格子布置，拖曳／點選／方向鍵移動、旋轉、收回、撤銷重做、桌面與座位擺飾及小屋擴建。
- 初始一千金幣；低於一百時，完成三次小互動及二十秒準備後補到三百，共用三分鐘補助冷卻。

## 九款刮刮樂

三圖相同、幸運號碼、小屋驚喜各有 20／100／500 金幣版面與獨立票框；分別有六、十、十五個區域。低面額簡單，中面額增加區域，高面額改為更大的版面並加入加碼配置。最高獎分別為面額的 10／10／20 倍。

三圖相同在同一橫排找出三個相同圖案；號碼票比對三個幸運號碼，中高面額可同時命中多個獎項；小屋票在各房間位置揭曉金幣，中高面額獎金分散在多個區域。顯示的獎項總和與結算一致。

整張票共用一層覆膜與一個 pointer capture，手指不用抬起即可跨區。刮筆以畫面尺寸計算，補足快速滑動中間的路徑；金屬刮屑與聲音回應操作。刮痕、區域揭曉及預先決定的獎金一起保存；大部分刮開後可補刮角落，「全部揭曉」為次要操作，收獎只執行一次。

舊版九格票券保留其既定結果與部分刮痕，可接續完成，不重新抽獎。雙擊、雙指縮放、舞台拖動及短時間在同位置重複點擊都有防護；對話框保留原生內部捲動。

## 存檔與素材

`cxq-lucky-town-v1` 使用封裝及 checksum，在 localStorage 和 IndexedDB 各保存一份，保留最近五份有效紀錄。扣款及結果先保存再演出；重整接續結算。Web Locks 序列化跨分頁提交；過時分頁取得最新紀錄後要求重試，小屋編輯也檢查房間是否被其他分頁修改。

匯入驗證物品、角色套裝、家具數量和位置、下注、刮卡狀態及 checksum；確認前顯示摘要，還原前備份目前紀錄。全部副本受損時保留原始資料，阻止新紀錄覆蓋，接受有效備份恢復。這是本機存檔，清除網站資料可能清除兩份儲存，請保留下載的 JSON 備份；沒有雲端同步。

內建 imagegen 生成獨立美術，原有角色作為身份參考。部署三百三十三張 WebP；本次新增一百零四張，包括橫式封面、九款票框、八十張步行中間姿勢、十張原裝慶祝圖及四張寵物慶祝圖。原始 PNG 留在本機，方向、參考及生成輸出記錄見 `art/generation-v3-prompts.json`；前版記錄亦保留。

四段音樂及十三種音效：Kenney CC0 音效；Kevin MacLeod 的 Carefree、Daily Beetle、Pixelland、Wallpaper 使用 CC BY 4.0，已註明作者、來源、授權與剪輯。來源見 `audio/sources.json` 及設定中的製作名單。音樂／音效獨立音量，首次操作解鎖，換場淡入淡出，背景分頁暫停。

## 驗證

從儲存庫根目錄執行：

```
node tools/test-lucky-town.mjs
node tools/test-lucky-town-v2.mjs
node tools/test-lucky-town-v3.mjs
node tools/serve-lucky-town.cjs
node tools/check-lucky-town-full.cjs
```

完整瀏覽器檢查涵蓋七種橫式尺寸（640×360、667×375、844×390、915×412、1024×768、1280×720、1600×900）、直式轉向提示、連續觸控與快速跨區刮除、重整續玩、雙擊、雙指手勢、畫面位移、六機台及 1／50 倍下注、四十套角色素材、站坐漸變、大獎與略過、小屋布置、照片下載、JSON 匯出／匯入、補助門檻、舊版退款、50 倍中斷結算、受損恢復、跨分頁、三百三十三張圖及十七個音訊解碼。

使用 `LUCKY_TOWN_URL` 指定遊戲網址，`CAILUCKY_URL` 指定網站根網址。報告及畫面留在本機 `preview/lucky-town/v3/`。手機尺寸與觸控模擬不等同 Android／iOS 實機驗收。
