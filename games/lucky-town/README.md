# CxQ 幸運小鎮

網站遊戲大廳入口標示「製作中｜可遊玩」。此版本使用純金幣：拉霸扣金幣、結算加金幣，家具、衣服與擴建都直接用金幣購買。

## 目前內容

- 10 個原有角色自由入場，各自保存小屋、穿搭、穿搭預設與拍照紀念；共用金幣和已購收藏。
- 6 種機台：中央連線、消除連鎖、鎖星免費重轉、花園累積、選軸保留重轉、相片累積。
- 24 件獨立家具素材、10 件個別角色新衣、3 件通用配件、3 種房間主題。
- 格子布置、拖曳／點選／方向鍵移動、旋轉、收回、撤銷重做、桌面與座位擺飾、房間擴建。
- 角色坐姿、家具互動、音效開關、快速旋轉與減少動態設定、照片下載。
- 初始 1,000 金幣；低於 100 時完成三次小互動及 20 秒準備，補到 300；共用 3 分鐘補助冷卻。

## 存檔

`cxq-lucky-town-v1` 使用完整封裝與 checksum，在 localStorage 和 IndexedDB 各保存一份，保留最近 5 份有效紀錄。旋轉扣款與預先決定的結果先持久保存，之後才播放與結算；重新整理會接續，避免重複發獎。Web Locks 序列化跨分頁提交，過時分頁載入最新進度後要求重試。小屋編輯檢查角色與房間是否遭其他分頁更新。

匯入先驗證格式、checksum、持有物品、角色穿搭、家具數量與位置；顯示預覽後才還原，且先備份目前紀錄。照片圖檔下載到裝置，相簿保存最近 20 次日期與名稱。清除網站資料仍可能清除兩份本機儲存，定期下載 JSON 備份才能獨立保留。此版本沒有帳號或雲端同步。

## 美術

使用內建 imagegen 工具，獨立生成封面、街區、空房間、UI 按鈕與面板、六台機器、符號、家具、角色新衣與坐姿。原有角色圖是身份參考，不替換網站其他遊戲的角色或封面。完整 PNG 留在本機 `art/`，生產版本用保留透明度的 WebP；不使用大拼圖裁成家具／角色。生成方向與來源記錄見 `art/generation-prompts.json`。

## 驗證

在儲存庫根目錄執行：

```
node tools/test-lucky-town.mjs
node tools/serve-lucky-town.cjs
node tools/check-lucky-town-full.cjs
```

瀏覽器檢查涵蓋購買扣款、換装、10 角色獨立入場、小屋操作、重新整理、真實下載／匯入備份、中斷旋轉、受損主紀錄恢復、跨分頁與補助冷卻、拍照，以及 320×568、390×600、390×844、412×915、1280×900 五種尺寸。QA 圖片與報告位於本機 `preview/lucky-town/`，不部署測試存檔。手機尺寸模擬不等同 Android／iOS 實機驗證。
