# CxQ 幸運小鎮 · 票券與固定控制版

版本：20261008-complete1。固定橫式、純金幣，十位夥伴各自有小屋、專屬套裝與寵物陪伴設定。遊戲首頁提供為幸運小鎮獨立繪製的返回遊戲中心按鈕。

## 操作與拉霸

一般切頁、選角、篩選不再受全域雙擊位置鎖攔截。正常儲存操作依序執行，不丟棄後續點按；購買與收獎有獨立防重複判定，存檔狀態不遮擋按鈕。禁止雙擊縮放、捏合放大與頁面偏移，直式顯示旋轉提示。

六台保留中央連線、消除連鎖、鎖星重轉、累積開花、保留重轉、相簿組合特色。六種圖案各有獎金表，每台都有實際獎金明細及得獎圖案提示；轉軸逐軸轉動與停下，連鎖補落、鎖星及大小獎演出配合真實結算。

下注倍率：使用左右箭頭選擇 1～500 倍，點按增減 1 倍，長按逐步加速。每次消耗與旋轉按鈕同步顯示金額；旋轉及待收獎期间鎖定倍率。下注與獎金等比例放大，機率不變；各倍率累積進度獨立保存。

## 五種面額，十款獨立票券

每個面額對應兩款獨立產品。每款有固定面額、獨立生成的點陣美術票面、刮區配置、規則及可達最高獎金。銀膜與新符號也使用獨立美術素材，依票面實際空白區定位；銀膜解碼前不能開始刮除。整張銀膜可連續跨格刮除，刮除進度及待領獎項會保存。舊 SVG 僅保留給已購入的舊版票券相容使用。

| --- | --- |
| 20 | 午茶三連：兩排各自三同；口袋零錢：金幣格獎金相加 |
| 50 | 星願號碼：對號領取該格獎；雙島尋寶：各島三把鑰匙開自己的寶箱 |

獎金依票面重新計算並驗證，最高獎項均可由合法票面達成。已購入的版本1／3／4舊票維持原規則、進度與獎金；新版票為layoutVersion5，沿用現有存檔格式，以獨立的 tickets-v5 主紀錄與 IndexedDB 鏡像承接 v4 存檔，避免舊分頁覆蓋新版票券。

拉霸控制分為固定倍率區、結果區、主按鈕與預留附加操作區。各階段與額外明細不改變主按鈕的位置；控制按鈕取消滑鼠懸停位移。

## 更大的小屋與寵物

房間主場景改為 2.5:1 寬畫面，手機橫式主要尺寸中房間占約 78% 可用寬度。人物與家具維持原比例，工具收進家具抽屜。布置有占用格、綠／紅預覽與原因、桌面及坐墊吸附、拖曳／點格、翻向、撤銷、重做、取消及套用。每位角色可保存三組完整布置方案，包含背景、窗景、家具與擴建大小。

保留 88 件家具、80 套角色專屬服裝、90 種造型、12 種房間背景與六種可購窗景。全部 90 種造型新增獨立躺姿，椅子與沙發使用坐姿定位，床使用躺姿定位及家具前緣遮擋；人物先走到可到達的空位再互動，已在家具旁可直接坐／躺。

寵物由四種增加至十二種：雲朵貓、葉芽兔、星糖犬、月光刺蝟、奶油花貓、棉糖垂耳兔、柴柴小隊長、楓葉小狐狸、栗子刺蝟、晨露小鹿、星羽貓頭鷹、泡泡史萊姆。新增寵物各有站立、兩步走路、睡覺與慶祝素材。自由散步／跟隨按角色保存，路線避開家具，畫面刷新保留寵物位置及路線。金幣領養、自由命名，沒有每日餵養負擔。

## 存檔與備份

資料版本 4，讀取並升級原有版本 1／2／3。保留金幣、收藏、套裝、房間、窗景、各倍率進度、寵物名字、未結算旋轉及部分刮卡。新受保護主紀錄与 IndexedDB 鏡像獨立于舊版存檔，舊分頁即使寫入較高修訂號也不會洗掉新版資料。

完整性檢查、最近五份輪替備份、損壞原稿保留、JSON 匯出／匯入與還原確認沿用。備份頁顯示本機與獨立鏡像實際寫入狀態。清除網站資料仍可能刪掉兩份瀏覽器資料；下載的備份才是裝置上的獨立副本。備份可由小鎮櫃台或設定開啟。
