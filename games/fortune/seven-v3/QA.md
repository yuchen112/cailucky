# CxQ 占卜館整合驗證

版本：20261009-oracle1。正式發佈為一次整合交付。

## 內容與規則

- 78 張塔羅各自正位、逆位、關鍵詞與行動建議；單張、處境／阻力／方向、關係及選擇四種陣式。完整洗牌，從七張牌列自由選取，牌位按抽取順序分配，不重複。
- 十二星座每日／每週：Astronomy Engine 的七顆星體地心黃道位置；台灣日期、週一至週日；七天月亮重點、主要相位與計算度數。不是出生星盤。
- 生命靈數含 11、22、33；曆年制個人年／月。驗證閏日、無效生日、未來日期、跨年。
- 六十四卦文王序與全部二進位圖案；三錢法八種結果機率 1:3:3:1；六爻由下而上，動爻變卦。64 則各自白話、留意事項、行動；爻位提示明示 CxQ 現代編寫。
- 24 首原創籤詩、24 枚古弗薩克符文、十位角色與小箱子。
- 全類內容可自由查閱及搜尋；新舊手帳分開保存。

## 驗證程式

`node tools/test-fortune-seven.mjs`：8 組，涵蓋全部內容數量／唯一性、78 張各自正逆位、64 卦完整覆蓋、三錢機率、500 輪牌陣不重複、星象春分基準及跨週跨年。

`node tools/test-fortune-storage.mjs`：14 個有效／無效備份案例，限制來源格式、長度、外部圖片網址、符文字元、卦象、牌號。

`node tools/test-fortune-art.mjs`：所有獨立美術解碼、78 牌面與 11 角色路徑、返回美術路徑。

`node tools/test-polish-audio.mjs`、`node tools/test-polish-audio-paths.mjs`：手勢解鎖、靜音恢復、暫停、背景、播放清單、錯誤回復、音效變化及打包後相對路徑。

`node tools/check-fortune-scope.mjs`：主網站只改小箱子占卜連結、名稱與資源版本；保留舊手帳鍵，未改 app.json 路徑。

## 瀏覽器實際操作

本機：七類均走到結果；塔羅非順序選第 7／2／5 張，按抽取順序分配牌位；選擇牌陣 A／B；七日星座解讀；2000-02-29 生日；六次起卦；籤詩完整四句與白話；三符文；小箱子角色結果；手冊搜尋展開；筆記儲存、重新載入、完整閱讀、匯出下載及合併匯入不重複。

主網站小箱子 → 占卜館 → 網站首頁往返；舊占卜入口、舊手帳與返回位置。窄手機曾發現返回列擠壓，修正後實際 320px 的 clientWidth／scrollWidth 均 305px；844px 橫向均 829px。另檢視 390px 與桌面版畫面。

音樂設定可開關、試聽，頁面顯示音樂播放中，操作後無 JavaScript 錯誤。此項不代表已用實體揚聲器或手機耳機聽驗。
