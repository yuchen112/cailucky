使用指南

安裝與開啟

  1. 使用 Windows 10 版本 2004 或更新版本的 x64 電腦。從本頁下載安裝檔，等下載完成再開啟。
  2. 若是更新，先關閉正在執行的工作台，再執行新版安裝檔，依畫面指示完成安裝。
  3. 從 Windows 開始功能表開啟「CxQ 工作台」，按「使用 Google 登入」，在瀏覽器完成登入後回到工作台。左側底部可確認登入的名稱與信箱。

下載或安裝被安全性軟體攔截時

瀏覽器、Windows Defender SmartScreen 或其他防毒軟體可能在下載、開啟或安裝時顯示警示。「無法辨識的應用程式」通常是信譽警示。若防毒軟體回報威脅名稱或隔離檔案，先暫停安裝。

  1. 確認檔案來自本頁的官方 GitHub 下載連結。可用 PowerShell 執行 Get-FileHash -Algorithm SHA256 並指定下載的檔案，將結果與 官方 SHA-256 校驗值比對。
  2. 在「Windows 安全性 → 病毒與威脅防護 → 保護歷程記錄」，或你使用的防毒軟體中查看警示內容。若校驗值不同或仍有威脅警示，請停止安裝，透過官網聯絡管道提供版本、警示名稱和截圖。請保持安全性防護開啟。

Microsoft 的保護歷程記錄說明

影音下載

  1. 貼上網址，確認「讀取模式」與輸出資料夾，再按「讀取作品」。預設會自動判斷，也可指定單一作品、作者或播放清單。
  2. 清單出現後勾選作品並加入佇列。播放清單會在輸出位置建立專用資料夾。
  3. 按「開啟下載佇列」，再按「開始下載」。管理視窗可調整大小，完成後從「下載歷史」開啟成品或所在位置。

需要登入時，可先進入「平台帳號」選擇平台。網址欄旁也有「瀏覽器解析」入口。下載你有權存取的內容。

檔案轉檔

  1. 加入檔案或資料夾，也可直接拖入。
  2. 選擇輸出資料夾，確認清單中各檔案的格式。批次工具可套用同一格式到相容檔案。
  3. 將清單加入轉檔佇列後按「開始／繼續」。完成後可開啟輸出資料夾或儲存轉檔報告。

AI 影像增強

  1. 加入圖片或影片，選擇輸出資料夾。
  2. 選擇素材並按「產生對照預覽」，以滑桿比較原始與增強畫面。倍率和模型可在「增強參數」設定。
  3. 確認效果後加入佇列，按「開始／繼續」。完成後從紀錄開啟成品。

電腦管理

  1. 在「螢幕管理」選擇螢幕。硬體亮度可用時調整並套用，也可使用軟體調暗。
  2. 在「睡眠聽歌」設定停止時間並開始計時。
  3. 在「資源監控」查看即時用量，或在「系統工具」開啟對應的 Windows 功能。

官網與遊戲館

左側的「CxQ 官網」與「CxQ 遊戲館」是獨立入口。從遊戲館選擇作品後，遊戲會在獨立視窗開啟。具備方向設定的作品會以對應的橫向或直向比例顯示。

常見問題

手機可以安裝嗎？

安裝檔適用於 Windows x64 電腦。可以用手機複製本頁連結，再到電腦下載。

影音清單讀不到，或平台頁打不開怎麼辦？

先檢查網址和讀取模式。若作品需要登入，請到「平台帳號」確認登入狀態。平台回傳錯誤時，可重新開啟平台再試。

關閉下載管理視窗會停掉下載嗎？

只關閉下載管理子視窗時，工作台仍可繼續處理佇列。重新開啟即可查看進度。

清除下載歷史會刪掉成品嗎？

「清除已完成紀錄」與「移除紀錄（保留檔案）」會移除工作台紀錄，成品留在輸出資料夾。
